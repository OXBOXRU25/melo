# MELO — тема WordPress

Классическая тема с двумя шаблонами внутренних страниц. Общее у них: интро с матовым стеклом, «Как мы работаем», «Примеры реализации», подвал. Различается второй блок.

| Шаблон | Второй блок | Файл |
|---|---|---|
| **Направление деятельности** | «Направления деятельности» — слайдер карточек с фотографиями, номерами и списками услуг | `template-direction.php` |
| **Услуга (что входит)** | «Что входит в услугу» — список позиций с иконками слева, большая картинка справа | `template-service.php` |

Оба шаблона выбираются в редакторе страницы и берут заголовок, подзаголовок и фон первого экрана из самой записи, поэтому страниц на каждом можно завести сколько угодно.

## Установка

**Способ 1 — через админку.** Внешний вид → Темы → Добавить новую → Загрузить тему → выбрать `melo.zip` → Установить → Активировать.

**Способ 2 — по FTP.** Скопировать папку `melo` в `wp-content/themes/`, затем активировать в админке.

## Первая настройка

1. **Создать страницу.** Страницы → Добавить новую. Заголовок станет `H1` на первом экране.
2. **Выбрать шаблон.** В правой панели редактора: Страница → Атрибуты страницы → Шаблон → **«Направление деятельности»** или **«Услуга (что входит)»** — смотря какой второй блок нужен на этой странице.
3. **Изображение записи** станет фоном первого экрана. Нужен горизонтальный кадр примерно 1920×1069. Если не задать — возьмётся `assets/img/hero.jpg`.
4. **Цитата** (Отрывок) станет подзаголовком под `H1`. Если поле скрыто: Настройки экрана → Отрывок. Без неё подставится текст по умолчанию.
5. **Хлебные крошки.** По умолчанию во второй крошке стоит название страницы. Чтобы сократить — добавить произвольное поле `melo_crumb` со значением вроде «Дизайн интерьера».
6. **Меню.** Внешний вид → Меню. Создать два и назначить их областям «Основное меню (шапка)» и «Меню в подвале». Пока меню не назначены, показывается запасной список из `functions.php`.
7. **Логотип.** Внешний вид → Настроить → Свойства сайта → Логотип. Пока не загружен, используется `assets/img/logo.png`.

## Где что править

| Что | Где |
|---|---|
| Телефоны, почта, адрес, оффер в подвале | `functions.php`, функция `melo_contact()` |
| Карточки «Направления деятельности» | `template-direction.php`, массив `$cards` |
| Позиции «Что входит в услугу» | `template-service.php`, массив `$service_items` |
| Заголовок и картинка блока услуги | `template-service.php`, `$service_title` и `$service_image` |
| Этапы «Как мы работаем» | оба шаблона, массив `$steps` |
| Примеры реализации | оба шаблона, массив `$projects` |
| Иконки для блока услуги | `header.php`, SVG-спрайт вверху файла |
| Цвета, кегли, отступы | `assets/css/tokens.css` |
| Внешний вид блоков | `assets/css/components.css` |

Контакты можно переопределить и без правки темы — фильтром в плагине или `functions.php` дочерней темы:

```php
add_filter( 'melo_contacts', function ( $data ) {
	$data['phone']      = '+7 843 000 00 00';
	$data['phone_raw']  = '+78430000000';
	$data['email']      = 'hello@melodesign.ru';
	return $data;
} );
```

## Перевод блоков на записи

Массивы в шаблоне сделаны так, чтобы их можно было заменить на выборку, не трогая вёрстку. Например, для примеров реализации: создать произвольный тип записи `project`, заменить массив `$projects` на `WP_Query`, а внутри цикла подставить `the_title()`, `the_post_thumbnail_url()` и произвольные поля. Разметка `foreach` остаётся прежней.

## Шрифты

Golos Text (текст) и Merriweather (заголовки) подключаются с Google Fonts. Для российского хостинга их лучше положить локально: скачать файлы в `assets/fonts/`, описать `@font-face` в `tokens.css` и убрать постановку в очередь стиля `melo-fonts` из `functions.php`. Это уберёт внешний запрос и ускорит первую отрисовку.

## Что важно знать

- **Блоки появляются при прокрутке.** До появления они скрыты, поэтому в `header.php` стоит инлайновый скрипт: он прячет блоки только при живом JS и принудительно показывает всё, если `main.js` не загрузится за 2.5 секунды. Не удаляйте его — иначе при сбое скрипта страница окажется пустой.
- **Липкая шапка и панель админа.** Пока вы залогинены, шапка сдвигается вниз на высоту админ-панели — это учтено в `style.css`.
- **Матовое стекло** на первом экране (`backdrop-filter`) не поддерживают совсем старые браузеры. Там останется просто плотная заливка, текст читается в любом случае.
- **Иконки блока услуги** лежат SVG-спрайтом в начале `header.php` и рисуются `currentColor` — цвет задан один раз на круге в `components.css`. Чтобы добавить свою: положить `<symbol id="i-имя">` в спрайт и указать это имя в поле `icon` массива `$service_items`.
- **Картинка блока услуги** идёт после списка и в разметке. На широких экранах она встаёт справа, ниже 860px поднимается под заголовок средствами CSS — порядок чтения при этом не меняется.

## Перенос в существующую тему

Если своя тема уже есть, целиком ставить эту не нужно. Достаточно:

1. скопировать `assets/` в свою тему;
2. скопировать `template-direction.php`;
3. перенести из `functions.php` постановку стилей и скриптов в очередь, функцию `melo_img()` и класс `Melo_Nav_Walker`;
4. перенести разметку шапки и подвала в свои `header.php` и `footer.php`.
