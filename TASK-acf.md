# Задача: вывести содержимое страниц MELO в админку

Поставлена 24 августа 2026. Причина простая: весь текст наших страниц
зашит в PHP-массивы внутри шаблонов, и заказчик его не видит и не может
править. В админке при этом лежит старое наполнение от прежнего проекта
(на «Контактах» — текст про cookie), отчего страница выглядит чужой.

## Как делаем

Поля регистрируем **кодом**, через `acf_add_local_field_group()` в новом
файле `inc/melo-fields.php`, а не руками в админке. Причины:

* группы едут вместе с пакетом и лежат в git — на другом сайте поднимутся сами;
* не нужно кликать полсотни раз и потом повторять это на боевом;
* значения при этом хранятся как обычно и правятся из админки.

Привязка групп — по шаблону страницы (`page_template`), чтобы поля
появлялись только там, где нужны.

Шаблоны переписываем так, чтобы читали ACF, а нынешние массивы
оставались значением по умолчанию: пустое поле не должно обнулять
страницу.

После этого — разовый скрипт, который переносит текущее содержимое в
поля, чтобы заказчик увидел готовый текст, а не пустые формы.

## Карта полей

Ключи сняты из шаблонов, а не придуманы.

### Контакты — `templates/template-melo-contacts.php`

| Поле | Тип | Что это |
|---|---|---|
| `melo_lead` | textarea | лид первого экрана |
| `melo_ways` | repeater ×4 | способы связи |
| → `icon` | select | phone / mail / pin / clock |
| → `role` | text | «Телефон», «Почта» |
| → `value` | text | значение; пусто — берём из настроек сайта |
| → `href` | text | ссылка, может быть пустой |
| → `note` | text | приписка под значением |

Мессенджеры уже правятся из «Общих настроек», трогать не надо.

### Страница услуги — `templates/template-melo-service.php`

| Поле | Тип | Что это |
|---|---|---|
| `melo_lead` | textarea | лид первого экрана |
| `melo_service_title` | text | заголовок «Что входит в услугу» |
| `melo_service_image` | image | картинка блока |
| `melo_service_items` | repeater ×5 | пункты: `icon` (select), `title`, `text` |
| `melo_steps` | repeater ×4 | «Как мы работаем»: `title`, `text` |

### Страница направления — `templates/template-melo-direction.php`

То же, что у услуги, плюс:

| Поле | Тип | Что это |
|---|---|---|
| `melo_cards_title` | text | заголовок раздела карточек |
| `melo_cards` | repeater ×5 | `img` (image), `alt`, `title`, `lead`, `items` |

### Главная — `templates/template-mainpage-updated.php`

`melo_cards_title` и `melo_cards` — те же, что у направления. Остальное
на главной уже из ACF.

## Порядок работы

1. `inc/melo-fields.php` — регистрация групп.
2. Контакты: шаблон читает ACF → проверка → заливка.
3. Страница услуги, затем направления, затем главная — тем же порядком.
4. Скрипт переноса нынешних текстов в поля, отдельно на локальной и на боевой.
5. Убрать из редактора «Контактов» старый текст про cookie.

## Чего не делаем

Иконки в `select` остаются кодом: это id символа из спрайта, а не текст,
и свободный ввод там сломает разметку молча.
