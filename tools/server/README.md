# Серверная часть: сжатие

Замер от 24 августа 2026 по главной странице: текстовых файлов (документ,
стили, скрипты) **1103 КБ**, в сжатом виде они же — **321 КБ**. То есть на
первой загрузке впустую едет **782 КБ, 71 %**.

Сжатие на сервере было выключено полностью — ни `gzip`, ни `brotli`.

## Что уже сделано

Файл `user.ini` из этой папки залит в корень сайта под именем **`.user.ini`**.
Он включает сжатие того, что отдаёт PHP, то есть самого документа:

| | было | стало |
|---|---|---|
| Главная | 65,5 КБ | 12,9 КБ |
| Контакты | 47,6 КБ | 9,8 КБ |
| Страница направления | 50,3 КБ | 10,9 КБ |

Работает без перезапуска: PHP перечитывает `.user.ini` сам, с задержкой
до пяти минут.

Почему только документ: стили и скрипты отдаёт **не PHP, а сам nginx**, и
его сжатие включается только в конфиге сервера. Проверено — `.htaccess`
на этом сервере не слушается вовсе (правило перенаправления в нём не
сработало), значит Apache в цепочке нет и обойти конфиг нечем.

## Что надо попросить у хостинга

Осталось **729 КБ** на первой загрузке — это стили и скрипты. Их сжимает
только nginx. Просьба к поддержке, дословно:

> Здравствуйте! На сайте melodesign.ru отключено сжатие статики.
> Добавьте, пожалуйста, в конфигурацию nginx для этого домена:
>
> ```nginx
> gzip on;
> gzip_comp_level 5;
> gzip_min_length 1024;
> gzip_proxied any;
> gzip_vary on;
> gzip_types
>     text/plain text/css text/xml
>     application/javascript application/json
>     application/xml application/rss+xml
>     image/svg+xml font/ttf font/otf;
> ```
>
> Если собран модуль brotli — включите заодно и его, с тем же списком
> типов. Спасибо!

`gzip_types` намеренно **без** `text/html`: он сжимается всегда и в
перечислении не нуждается, а вот картинки (jpg, png, webp) в список
попадать не должны — они уже сжаты своим форматом, и gzip только тратит
процессор.

## Как проверить, что заработало

```
curl -s -o /dev/null -D - -H "Accept-Encoding: gzip" https://melodesign.ru/wp-content/themes/oxboxwise/js/main.min.js | grep -i content-encoding
```

Должно ответить `content-encoding: gzip`. Сейчас не отвечает ничего.

## Если сжатие HTML понадобится выключить

Удалить `.user.ini` из корня сайта. Ничего больше он не делает.
