==========================================================

КАК ПОСМОТРЕТЬ ВЁРСТКУ

Откройте index.html в браузере — это первая страница. Вторая лежит рядом,
файлом arhitekturnoe-proektirovanie.html. Всё загрузится с диска: стили,
скрипт, фотографии. Шрифты (Golos Text и Merriweather) тянутся с Google
Fonts, поэтому для точного вида нужен интернет.

Страницы отличаются вторым блоком. На первой это «Направления
деятельности» — слайдер карточек с фотографиями. На второй «Что входит
в услугу» — список позиций с иконками и одна большая картинка. Всё
остальное у них общее.


КАК ПОСТАВИТЬ ТЕМУ НА WORDPRESS

1. Админка → Внешний вид → Темы → Добавить новую → Загрузить тему
   → выберите wordpress/melo.zip → Установить → Активировать.

2. Создайте страницу и в блоке «Атрибуты страницы» выберите шаблон:

   «Направление деятельности»  — второй блок будет слайдером карточек
                                 (как на dizayn-interera-i-eksterera.html)
   «Услуга (что входит)»       — второй блок будет списком с иконками
                                 (как на arhitekturnoe-proektirovanie.html)

   Шаблоны универсальные: заголовок, подзаголовок и фон берутся из самой
   записи, поэтому страниц на каждом можно завести сколько угодно.

3. Что во что превращается:

   Заголовок страницы          →  H1 первого экрана
   Цитата (excerpt)            →  подзаголовок под H1
   Изображение записи          →  фотография первого экрана
   Произвольное поле melo_crumb →  короткая подпись в хлебных крошках
                                   (если пусто — берётся заголовок)

4. Меню: Внешний вид → Меню, назначьте на область «Основное меню»
   и «Меню в подвале».

Подробнее — в wordpress/melo/README.md.


ГДЕ ПРАВИТЬ СОДЕРЖИМОЕ

Содержимое блоков лежит PHP-массивами в начале шаблонов:

  wordpress/melo/template-direction.php
      $cards     — карточки «Направления деятельности»
      $steps     — этапы «Как мы работаем»
      $projects  — примеры реализации

  wordpress/melo/template-service.php
      $service_title, $service_image  — заголовок и картинка блока
      $service_items                  — позиции «Что входит в услугу»
      $steps, $projects               — то же, что выше

Правятся там же либо заменяются на ACF / произвольный тип записи —
циклы вывода при этом менять не нужно.

Иконки блока услуги лежат SVG-спрайтом в начале wordpress/melo/header.php
и рисуются currentColor. Чтобы добавить свою: положить <symbol id="i-имя">
в спрайт и указать это имя в поле icon массива $service_items.


ЧЕГО НЕ ЛОМАТЬ

1. Появление блоков. Элементы с атрибутом data-reveal до появления стоят
   в opacity: 0. Прятать их разрешено только при живом JS — класс .js ставит
   инлайновый скрипт в <head>, а если main.js не поднимется за 2.5 секунды,
   срабатывает аварийный показ .reveal-failsafe. Уберёте одно из двух —
   при сбое скрипта страница окажется пустой.

2. Положение блоков считается через getBoundingClientRect по событиям
   scroll, resize и load — НЕ через IntersectionObserver. Наблюдатель
   присылает результат асинхронно и только когда браузер рисует кадр,
   а прокрутку браузер восстанавливает уже после выполнения скриптов.
   Из-за этого при F5 на середине страницы видимая часть оставалась
   пустой. Этот баг уже ловили — не возвращайте наблюдателя.

3. Аварийный показ фотографий должен быть специфичнее правила, которое
   их прячет. Селекторы в base.css рассчитаны, лишние классы из них
   убирать нельзя.

4. У .card__media и .project__media подъём, тень и шторка перечислены
   ОДНИМ объявлением transition. Разнести их по разным правилам нельзя:
   сокращённая запись transition заменяет весь список целиком.

5. Пересобирать архив темы через Compress-Archive нельзя — она пишет пути
   с обратными слешами, и macOS распакует кашу. Используйте
   tools/build-package.ps1 либо System.IO.Compression.ZipArchive.


ЧТО ЕЩЁ НЕ СДЕЛАНО

  • Фотографии — плейсхолдеры, вырезаны из макета. Нужны настоящие рендеры;
    пропорции и пути уже проставлены.
  • Логотип прислан только растром 196×54, для ретины нужен SVG.
  • Шрифты тянутся с Google Fonts. Для российского хостинга положите
    локально в assets/fonts/.
  • Контакты и телефоны — рыбные.
  • Главная страница не вёрсталась, поэтому пункты меню ведут на
    index.html с якорями, которых пока нет.
